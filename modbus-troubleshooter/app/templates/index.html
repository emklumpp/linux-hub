API Endpoints

Available Endpoints:

  • GET /api/devices - List all devices
  • POST /api/devices - Add new device
  • POST /api/test/connection - Test device connection
  • POST /api/registers/read - Read registers
  • POST /api/registers/write - Write registers
  • GET /api/plc/status - Get PLC status
  • GET /api/diagnostics/report - Generate diagnostic report
  • GET /api/logs - View transaction logs
  • GET /api/stats - Get statistics
